# JellyNet

## Platform

web

## Stack

TypeScript and CSS inside Jellyfin Web, delivered by a .NET plugin using File Transformation.

## Users

Household viewers on desktop, phone, and remote-controlled screens. Server administrators curate shared shelves and plugin links.

## Product Purpose

Help viewers resume playback, find a title by category, and make their Jellyfin home their own.

## Capabilities and Constraints

Retain Jellyfin accounts, library access, favorites, playback, and existing plugin destinations. The enhanced theme runs in compatible Jellyfin Web clients. Native interfaces use their built-in presentation. Publishing requires explicit approval.

## Accessibility & Inclusion

Support keyboard, touch, and directional focus. Keep artwork optional for comprehension and honor reduced motion.
